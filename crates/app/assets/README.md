# Иконка Nozhik

`source.png` — точная копия предоставленного владельцем `docs/img/logo.png`
(512×512, RGBA). Пропорции и прозрачность сохранены; дополнительных полей нет.

- `nozhik.png`: мастер 1024×1024.
- `window-icon.png`: 256×256 для встроенной viewport icon и логотипа стартового окна.
- `nozhik.ico`: Windows, размеры 16/24/32/48/64/128/256.
- `nozhik.icns`: macOS, размеры 16–1024 с Retina-представлениями.

Конвертация выполнена Pillow: RGBA, масштабирование LANCZOS, PNG/ICO/ICNS
encoders. Готовые файлы включены в Git; Pillow при сборке не требуется.
После замены ресурсов обновляйте текущую платформу через
`python3 scripts/update-binaries.py`; Windows собирается только по явному запросу.
