# Иконка Nozhik

`source.webp` — предоставленное владельцем изображение с прозрачностью.
Рисунок сохранён без изменения пропорций. Он вписан в область 896×896
на прозрачном холсте 1024×1024 и выровнен по центру.

- `nozhik.png`: мастер 1024×1024.
- `window-icon.png`: 256×256 для встроенной viewport icon.
- `nozhik.ico`: Windows, размеры 16/24/32/48/64/128/256.
- `nozhik.icns`: macOS, размеры 16–1024 с Retina-представлениями.

Конвертация выполнена Pillow: RGBA, `ImageOps.contain` с LANCZOS,
`alpha_composite` на прозрачный холст, затем PNG/ICO/ICNS encoders.
Готовые файлы включены в Git; Pillow при сборке приложения не требуется.
После замены ресурсов пересобирайте обе платформы через update-binaries.py.
