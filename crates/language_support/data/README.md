# Generated PHP catalogs

Generated by `scripts/generate_php_stubs.php` in official `php:<level>-cli-alpine`
images for Linux/amd64. All 11 supported levels are embedded in the application.
User files in `~/.nozhik/languages/php/versions/` override these bundles.

Global entities include functions, classes, interfaces, constants and keywords.
Methods and class constants are nested under the owning class/interface.
All internal symbols from the listed loaded extensions are included; optional
extensions absent from the image (for example intl/gd/mysqli) are not included.
Legacy Reflection metadata may omit types; those types are recorded as `mixed`.
Doc comments absent from Reflection remain empty. Magic constants have no fixed
value. Other constant values reflect the Linux/amd64 generating environment.

`catalog-manifest.json` records image digests, runtime patch versions, extension
inventories and SHA-256 hashes of the generator and JSON files. No timestamps or
host paths are used as provenance. Docker image tags may change; use the recorded
repository digests to reproduce these exact runtime inventories.

From the repository root:

```sh
python3 scripts/generate-php-catalogs.py
python3 scripts/generate-php-catalogs.py --version 8.5
cargo run -p nozhik-language-support --example validate_php_stubs -- crates/language_support/data/php_8.5.json
```

Generation is sequential. Each successful container is removed with `--rm`, and
newly downloaded images are removed before the next level. Existing Docker images,
containers, volumes and build caches are preserved. No Docker prune is run.
